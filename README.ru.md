# 💬 Телеграм-бот: Крипто-Трекер

[🇬🇧 Read in English](README.md)

Этот бот помогает отслеживать цены криптовалют и прогресс вашего портфеля до заданной цели.  
Когда пользователь отправляет `+`, бот получает текущую цену выбранной монеты с Binance и рассчитывает прогресс портфеля в %.  

---

## 🚀 Возможности
- 📡 Получение актуальной цены монеты с Binance.
- 📊 Расчёт прогресса от текущей стоимости портфеля до цели в %.
- 💬 Простое взаимодействие: отправьте `+`, чтобы получить обновления.
